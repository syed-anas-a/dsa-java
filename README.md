## Approach

- Each problem is solved first for correctness, then revisited for an optimal solution.
- Multiple submissions in a folder show that progression — for example, a brute-force O(n²) pass replaced by a monotonic stack in O(n).
- Solutions favour readable, interview-style code over clever one-liners.

---

## Repository Structure

Solutions are synced automatically from NeetCode, one folder per problem:

